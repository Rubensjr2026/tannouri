# Edilaine Tannouri — Landing page

Página de fonoaudiologia da Clínica Tannouri, em Joinville.

## Arquivos

- `index.html`: página principal.
- `style.css`: aparência e adaptação para celular.
- `app.js`: interações, serviços e links de WhatsApp.
- `assets/`: logo, fotos e imagens.

Site estático: não precisa de instalação nem compilação.

## Usar no GitHub

1. Crie um repositório no GitHub.
2. Extraia o ZIP e envie todo o conteúdo desta pasta para a raiz do repositório. Mantenha a pasta `assets`.
3. Para publicar com GitHub Pages, selecione a branch que contém os arquivos e a pasta raiz (`/`).

O `index.html` deve ficar diretamente na raiz, ao lado de `style.css` e `app.js`.

## Visualização local

Abra `index.html` no navegador.
